# Project Guide

## Project

This is a promotional website for a small neighborhood bakery.

The first goal is to make a simple, warm, easy-to-read landing page that helps local customers quickly understand:

- What the bakery is called
- What kind of bread it sells
- Where it is located
- When it is open
- How to contact or visit

## Audience

The main visitors are nearby residents who may want to buy bread today.

They should be able to find important information quickly on a phone:

- Popular menu items
- Opening hours
- Address
- Phone number
- Social media or map link

## Site Sections

The first version should include:

1. Hero section
   - Bakery name
   - Short tagline
   - Main bakery or bread image
   - Visit or call button

2. Menu section
   - 3 to 6 representative items
   - Item names
   - Short descriptions
   - Prices if available

3. Store information section
   - Opening hours
   - Closed days
   - Address
   - Phone number

4. Location/contact section
   - Map link or placeholder
   - Contact button
   - Instagram or Kakao channel link if available

## Design Direction

The design should feel local, friendly, clean, and trustworthy.

Use:

- Clear readable text
- Warm but not overly dark colors
- Realistic bakery or bread images when possible
- Simple spacing
- Buttons that are easy to tap on mobile

Avoid:

- Complicated animations
- Too many colors
- Tiny text
- Long paragraphs
- A design that looks like a big corporate chain

## Technical Direction

Start with beginner-friendly files:

- `index.html` for page structure
- `style.css` for visual design
- `script.js` only if interaction is needed
- `images/` for photos

Use plain HTML and CSS first.

Do not add React, Vue, Next.js, build tools, or package managers until the basic website is working.

## Coding Rules

- Keep file names simple and lowercase.
- Use meaningful class names.
- Write HTML that is easy for a beginner to read.
- Keep CSS organized by section.
- Make the site work well on mobile first.
- Add comments only when they help explain a beginner concept.
